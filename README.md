## Introduction

Face Recognition (FR) is an important biometric technology used for identifying and verifying individuals based on their facial characteristics. It has been widely applied in security and surveillance, access control, attendance systems, authentication, and human–computer interaction. A typical face recognition system consists of several stages, including face detection, image preprocessing, feature extraction, and classification or matching. Among these stages, **feature extraction** plays a critical role because the quality and discriminative capability of the extracted facial features directly affect recognition performance.

Traditional face recognition approaches often rely on handcrafted texture descriptors to represent important facial patterns. **Local Binary Pattern (LBP)** is one of the widely used descriptors because of its computational simplicity and ability to capture local texture information. LBP represents the relationship between a central pixel and its neighboring pixels by comparing their intensity values and encoding the comparison into a binary pattern. However, conventional LBP mainly captures local texture relationships and can be sensitive to changes in illumination, facial expression, pose, and image quality.

To improve the representation of facial texture, **Orthogonal Combination of Local Binary Patterns (OC-LBP)** can be employed as an enhanced feature extraction approach. OC-LBP combines complementary local texture information obtained from different orientations or orthogonal neighborhood relationships. Instead of relying on a single local neighborhood representation, the method attempts to capture richer spatial texture characteristics from facial regions. This provides a more comprehensive representation of important facial structures such as the eyes, nose, mouth, cheeks, and surrounding regions.

In an OC-LBP-based face recognition system, the input facial image is first detected and normalized to reduce variations caused by scale, position, and illumination. The normalized face is then divided into suitable local regions, from which OC-LBP features are extracted. These features are converted into a discriminative feature representation and subsequently used for face matching or classification. Depending on the system design, classifiers such as Support Vector Machine (SVM), k-Nearest Neighbour (KNN), or distance-based matching methods can be used for recognition.

The major advantage of incorporating OC-LBP into a face recognition system is its ability to represent **local texture information from complementary spatial relationships**, potentially improving recognition accuracy compared with a basic LBP descriptor. It is particularly useful when facial images contain variations in illumination, expression, and local appearance. Therefore, OC-LBP provides a lightweight and interpretable feature extraction mechanism that can serve as an alternative or complementary approach to computationally intensive deep-learning-based feature extraction methods.

Thus, an **OC-LBP-based Face Recognition System** focuses on improving facial feature representation through enhanced local texture analysis. The overall framework can be organized as **face acquisition → face detection → preprocessing and normalization → OC-LBP feature extraction → feature representation → classification/matching → identity recognition**. The effectiveness of the proposed approach can be evaluated using recognition accuracy, precision, recall, F1-score, false acceptance rate (FAR), false rejection rate (FRR), and computational efficiency.
